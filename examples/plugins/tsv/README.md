# TSV plugin for Green

The second format, added after the plugin system landed: **0 product code
files, no rebuild, no release**. Only this folder is new.

Copy it to Green's data folder under `plugins\tsv\` (on Windows,
`%LOCALAPPDATA%\Green\green\plugins\tsv\` unless the data folder was moved in
Settings). `.tsv` and `.tab` then open as a table.

The contract is the one in `../csv/README.md`.
